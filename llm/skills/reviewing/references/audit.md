# Review audit and evidence

For each candidate, retain the location, observed behavior or claim, supporting
source, impact, confidence, uncertainty, and requested next step. Re-check that
it still matches the current artifact, is not duplicated, is tied to a changed
line when posting, and has a concrete consequence and one action.

After six independent lenses, enumerate every candidate, merge only true
duplicates, and record why unsupported, duplicative, out-of-scope, or
non-actionable candidates were dropped. Report no-finding lens results too.

Before delivery, run the smallest real check available. For code suggestions,
use an isolated copy, run the narrow command before and after the proposed
shape, and record limitations. A final independent audit reads the skill,
pattern references, example catalog, and exact draft; it checks only that every
suggestion has a concrete example, then missing examples are added or findings
are dropped. Keep confirmed issues, inferences, and unverified concerns
separate, and do not use priority labels unless requested.
