## Examples

- **[examples.md](../assets/examples.md)** *(local)* — **Worked commit sequences:
  real working trees split into atomic, dependency-ordered commits with their
  exact `git add` / `git commit` commands and messages.** Read it to see the
  rules in `SKILL.md` applied end to end — how to group changes, order them so
  every commit leaves the repo working, stage precisely (leaving unrelated
  changes unstaged), and phrase the messages. Add new sequences here as more
  cases come up.
